# Keygen Web App

The Keygen Web App is a standalone Node.js (Express) application designed to securely generate activation keys for the FeesFoundry offline desktop application. 

Because FeesFoundry runs completely offline on client hardware, there is no centralized authentication server. Instead, it utilizes a symmetric HMAC-SHA256 hardware-locked licensing model.

## How It Works

1. **Client Hardware Fingerprint:** The desktop application generates a unique 12-character Machine ID (e.g., `DEAA1860B03D`) locked to the user's specific CPU and Motherboard.
2. **Client Communication:** The client sends this Machine ID (via a photo of the QR code or plain text over WhatsApp/Email) to the software administrator.
3. **Key Generation:** The administrator logs into this Keygen Web App, inputs the client's name and Machine ID, and generates a secure 16-character Activation Key (e.g., `129D-B1EA-1385-563C`).
4. **Activation:** The client enters this key into their desktop application, unlocking it for use.

## Security Model

This system relies on a **shared symmetric secret** (`LICENSE_SECRET`) hardcoded into both the Desktop Application and this Keygen Web App. 

- The Activation Key is generated by computing an HMAC-SHA256 hash of the Machine ID using the shared secret.
- The resulting hex hash is truncated to 16 characters and formatted with dashes for readability.
- Since the secret is never transmitted over the network, it remains secure against man-in-the-middle attacks, provided the desktop application binary itself is not reverse-engineered.

## Setup Instructions

This web app runs entirely independently from the main Electron application.

1. Navigate to the `keygen-webapp` directory:
   ```bash
   cd keygen-webapp
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```
   (Alternatively, use `node server.js`).
4. Access the web interface at `http://localhost:3000`.

## Default Credentials

The admin login is protected by a simple password authentication mechanism.
- **Default Password:** `admin123`

*Note: For production deployments, change this password and ensure the server is served over HTTPS to protect the login token.*
