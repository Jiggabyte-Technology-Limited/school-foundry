# Printing Analysis - FeesFoundry Electron App

## Overview

This Electron app uses **browser-based printing** via `window.print()` - the standard web printing API. There is **no native Electron printing** (no `webContents.print()` or `printToPDF()` IPC handlers).

---

## How Printing Works

1. **Trigger**: User clicks a "Print" button in the UI
2. **Execution**: `window.print()` is called in the renderer process
3. **Result**: Browser's native print dialog opens
4. **Output**: Uses the computer's default printer (or PDF export via "Save as PDF")

### Print Styling
- CSS `@media print` rules in `@/src/index.css:1411-1429` control what prints
- `.no-print` class hides buttons/filters during printing
- `.print-only` class shows hidden print-specific content
- A4 page dimensions are defined in `.a4-page` class (`@/src/index.css:1360-1371`)

## Technical Details

### Print Mechanism
```typescript
// Standard browser print
window.print()

// Or print via popup window (PaymentManager)
const printWindow = window.open('', '', 'height=800,width=1000');
printWindow.document.write(html);
printWindow.document.close();
setTimeout(() => printWindow.print(), 250);
```

### CSS Print Controls
- `@/src/index.css:1340-1429` contains all print-related styles
- `.no-print` - hidden during print
- `.print-only` - visible only during print
- `.a4-page` - 210mm × 297mm dimensions

### Electron Configuration
- `@/src/main.ts:13-22` - BrowserWindow created with `plugins: true` (for PDF support)
- No custom IPC handlers for printing
- Relies entirely on Chromium's built-in print functionality

---

## Limitations

1. **No PDF generation** - Can only print to physical printer or save as PDF via browser dialog
2. **No native print dialog customization** - Uses standard Chromium print dialog
3. **No batch PDF export** - Must print each document individually
4. **No email/auto-print** - Manual intervention required
5. **No network printer direct access** - Uses OS-level printer selection

---

## Potential Improvements

1. Add `webContents.printToPDF()` for direct PDF generation
2. Add IPC handler for print dialog customization (printer selection, copies)
3. Add batch PDF export for multiple student statements
4. Add email functionality to send statements directly
5. Add print preview modal with page navigation
