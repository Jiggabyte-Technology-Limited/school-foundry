# 🎨 FeesFoundry Branding Guide

This guide explains how to update the logos and icons for **FeesFoundry**.

## 📍 File Locations

Place your branding assets in the following locations:

| Asset | Location | Recommended Format | Description |
|---|---|---|---|
| **App Icon** | `public/img/feesfoundry-icon.svg` | **SVG** (square) | Used for the browser favicon and app icons. |
| **Main Logo** | `public/img/feesfoundry-logo.svg` | **SVG** (wide/square) | Used in the Sidebar and Login screen. |
| **Login Background** | `public/img/feesfoundry-logo.jpg` | **JPG/PNG** | Fallback or decorative logo. |

## 📐 Recommended Formats

1.  **SVG (Highly Recommended):**
    *   **Why:** Infinite scalability without losing quality. Small file size.
    *   **Best for:** Icons, text-based logos, and simple shapes.
    *   **How to provide:** You can paste the SVG code directly in our chat, and I can save it for you.

2.  **PNG (Transparent):**
    *   **Why:** Good for complex graphics that need transparency.
    *   **Best for:** Logos with gradients or photographic elements.
    *   **How to provide:** Upload the file to the `public/img/` directory on your machine.

3.  **ICO (Favicon):**
    *   **Why:** Traditional format for browser compatibility.
    *   **Best for:** `favicon.ico`.
    *   **Note:** The app currently uses the SVG icon as the favicon in `index.html`.

## 🛠️ How to Replace

1.  **Direct File Replacement:** Simply overwrite the files in `public/img/` with your new assets using the exact same filenames.
2.  **Code Update:** If you want to use different filenames, update the references in:
    *   `index.html` (Favicon)
    *   `src/components/Sidebar.tsx` (Sidebar Logo)
    *   `src/components/auth/Login.tsx` (Login Logo)
